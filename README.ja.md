 私について
私は WesleyA0101 です。デジタルの自由と 自由ソフトウェア を強く支持しています。Richard Stallman と Linus Torvalds に触発され、自由、透明性、知識の共有を活動の基盤とする、より開かれたデジタル世界の実現に貢献したいと考えています。

 主なプロジェクト
🔹 Roadmap__Bitwise-Journey-Rumo-Programacao-de-Baixo-Nivel
低レベルプログラミングのスキルを身につけるための学習ロードマップです。システムプログラミング、ハードウェア、最適化に関する知識を深めるためのガイドをまとめています。
🔹 Scanner_demon
ネットワークのスキャン、ホストの稼働状況の確認、IP アドレス上のポート分析を目的とした C 言語製ツールです。セキュリティ学習、監査、許可されたペネトレーションテストでの利用を想定しています。
🔹 Estudo-de-ransomware
ランサムウェアに関する調査や、マルウェアの仕組みを学ぶためのプロトタイプを記録するリポジトリです。情報セキュリティへの影響を含め、教育・研究目的で扱っています。
🔹 LFIvader
Web アプリケーションにおける Local File Inclusion（LFI）脆弱性の検出と、結果の整理を目的とした C 言語製スキャナーです。許可を得たセキュリティ評価での利用を想定しています。
🔹 PDF-Split-PRO
PDF のページ分割や、キーワードに基づくファイル名の自動変更を行うアプリケーションです。反復作業の自動化と文書整理を支援します。
