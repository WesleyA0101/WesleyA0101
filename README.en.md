 Relevant Projects
🔹 Bitwise Journey — Roadmap to Low-Level Programming
A study roadmap for developing skills in low-level programming, operating systems, and computer science fundamentals. Explore topics related to systems programming, hardware, and optimization.
🔹 Scanner Demon
A C-based tool for network scanning, host availability checks, and port analysis for an IP address. Designed for security study, auditing, and authorized testing.
🔹 Ransomware Studies
A repository documenting educational research into ransomware and malware development, including their techniques and implications for information security.
🔹 LFIvader
A C-based scanner designed to identify Local File Inclusion (LFI) vulnerabilities in web applications and organize findings for analysis during authorized security assessments.
